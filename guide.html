User Guide

How to use DRISHTI

  1. Check the Live Hazard Map for monitored locations.
  2. Use Risk Analysis to understand local susceptibility indicators.
  3. Monitor Weather & Rainfall before travelling through vulnerable areas.
  4. Review Alerts and Road Conditions before starting a journey.
  5. Submit verified observations through Citizen Report.
  6. Use SOS only during an emergency.
